# Riftfall — Magnesium Web Prototype

A playable 3D browser reconstruction inspired by the supplied lobby screenshot: solo bot skirmishes, a shrinking storm, rifle combat, wall/ramp building, supplies, practice mode, three outfits and saved settings. All scenery and characters are original low-poly geometry generated by the game.

**This is a new browser prototype.** It does not execute the Fortnite Windows client, load its `.pak`, or run the Magnesium DLL. The supplied archives do not include the editable Fortnite project needed for a conventional source port. Multiplayer, Fortnite accounts, matchmaking, the original map and original cosmetics are not implemented. Your actual launcher source has not been supplied, so compatibility with it remains unverified.

## Play on Windows

1. Double-click `PLAY.bat` with Node.js 22 or later installed.
2. Open **http://127.0.0.1:4173** in Edge, Chrome or Brave with graphics acceleration enabled.
3. Choose **Solo skirmish** or **Target practice**, select **Let's play**, then click the island to capture the mouse.

Keep the server window open. Ctrl+C stops it. The included `dist/vendor/babylon.js` is local; playing requires no npm install, CDN or account. Use an HTTP server instead of opening `index.html` as a file. To change ports, run `node scripts/serve.mjs --port 4174`.

| Input | Action |
| --- | --- |
| WASD / mouse | Move / look |
| Space / Shift | Jump / sprint |
| Left / right mouse | Fire or place build / aim |
| R | Reload |
| Q / 1 | Toggle building / equip rifle |
| E / F | Switch wall/ramp / rotate build |
| Escape | Pause |

Builds cost 20 wood. Collect glowing supplies for ammo, wood, health or shields. Stay inside the purple storm circle in skirmish mode. Practice targets respawn and do not shoot. Keyboard and mouse are required; the responsive lobby does not imply touch gameplay.

## Embed in a launcher

`dist/` is the complete static game. Bundle that directory in your launcher or serve it over HTTPS. Start with **http://127.0.0.1:4173/launcher-example.html** for a working browser-frame integration example.

```html
<iframe
  src="http://127.0.0.1:4173/?parentOrigin=https%3A%2F%2Flauncher.example"
  title="Riftfall"
  sandbox="allow-scripts allow-same-origin allow-pointer-lock"
  allow="fullscreen"
  allowfullscreen
  style="width:100%;height:100%;border:0"
></iframe>
```

Set `parentOrigin` to the launcher's **exact HTTP(S) origin**, without a trailing slash. If omitted, the game accepts messages only from a parent with the game's own origin. For native launchers using custom schemes, serve the launcher/game on a loopback HTTP origin or adapt the bridge after inspecting that launcher. A normal web page cannot start the Windows Fortnite executable or load a Windows DLL through this bridge.

Messages have `{ type, version: 1 }`. The launcher must check both `event.origin` and `event.source`; use the game's exact origin as the `postMessage` target.

| Direction | Message | Extra data |
| --- | --- | --- |
| Game → launcher | `riftfall:ready` | `capabilities` |
| Game → launcher | `riftfall:match-start` | `mode` |
| Game → launcher | `riftfall:match-end` | `result: { won, kills, score, elapsed, mode }` |
| Game → launcher | `riftfall:paused`, `riftfall:resumed`, `riftfall:exit` | — |
| Launcher → game | `riftfall:pause`, `riftfall:resume`, `riftfall:stop` | — |

Resuming by message restores simulation; a click inside the game may still be needed to capture the mouse. The bridge grants no filesystem, shell, native-process or account access. `window.riftfall.getState()` supplies a copy of the latest gameplay state for diagnostics.

## Development and verification

```text
npm ci
npm run vendor
npm test
npm run test:browser
npm run test:integration
npm run test:world
npm start
```

`npm run vendor` refreshes the local pinned Babylon.js engine, license and notice. Browser tests use installed Edge or Brave on Windows; set `RIFTFALL_BROWSER` to another Chromium executable, or install Playwright Chromium on other hosts. Screenshots and test results are written to `test-results/` and are not included in the game distribution.

The archive evidence and the requested Reverse-Engineer-anything CLI findings are in `docs/`. The CLI checkout is isolated in the ignored `tools/` directory, not shipped with the game. Its native Ghidra prerequisites are separate from those of this browser prototype.
