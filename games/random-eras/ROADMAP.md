# Rebuild roadmap

| Milestone | Working build |
| --- | --- |
| A. Combat feel | Directional strike rules and trails, hit feedback, guard timing, bot rhythm, tuning and weapon balance |
| B. World and visuals | Era scenery and atmosphere, parchment navigation and border notices, then editable Blender replacements |
| C. Campaign UI | Loadout, Career, match results, controls and a short Training drill |
| D. The Pit | Smaller invites, plain connection states, smoothing and host-authority notes |
| E. Reliability | Determinism and persistence tests, failure paths, asset budgets, browser and performance checks |

Build and test each milestone before committing. Keep the current daily seed format, era IDs and terrain rules so existing links still resolve. New visual dressing can be derived from the current world without changing collision or height data. Swipe stays the default, and the existing click setting remains available.

The original assets need an owner-approved license before release. The playable knight replacement also needs approval. Keep credits for each placeholder until its replacement ships.
