# Skybreak Classic

The original procedural Skybreak build-and-target arena, preserved from
`reference/skybreak-v1` in source commit
`8cc8ad39e5becaa38a8137bd22e0f6094ab69027`.

Runtime files and the bundled Three.js engine are in `dist/`. The Three.js licence
is retained in `dist/vendor/THREE-LICENSE.txt`. The original game code and artwork
are covered by the importing project's licence. Play on desktop with keyboard
and mouse: WASD movement, Space jump, Shift sprint, 1–3 equip, click shoot/build,
R rotate and Escape pause.

The root build publishes this game at `/games/skybreak-classic/`.
